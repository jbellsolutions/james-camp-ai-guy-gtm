## Data subscriptions and verification

Data Box is an optional repository, not a mandatory paid platform. The source is pinned in the [source lock](../sources.lock.json). Its listed providers are not all native adapters: Firecrawl, MoltSets, Bright Data and Apify have adapter source; other options require discovery and a capability probe. Source being present does not mean it has been installed, authenticated or tested here.

BrowserBox provides an alternate controlled browser route. Respect source access limits and record provenance; scraping does not guarantee complete coverage or supply email/SMS consent. Configure a bounded sample and spend cap before broad sourcing. A verification procedure is included, but an actual email-verification service must be connected separately. Consulti and existing verification accounts are options to evaluate, not live connections supplied by this repo.

## Choose a minimal stack

Uploaded list route: host + model + one sequencer + verification + sending mailboxes. Add GoHighLevel/registered SMS when continuing permitted text conversations. Add Slack for owner control. Add sourcing subscriptions only if they improve the actual audience. PlusVibe, Composio and affiliate management remain opt-in.

Record selected plan, owner, billing account, API availability, monthly ceiling and cancellation/recovery notes privately. Use the [ready-to-run checklist](READY-TO-RUN.md) and [toolkit inventory](TOOLKIT.md) to finish each connection.
