# Installation interview and private decision record

Collect only missing answers; reuse project documents.

| Decision | Options / record |
|---|---|
| Host | Existing Orgo computer ID or DigitalOcean VPS; owner/access, region, backup route |
| Installs | Cold Email / Conversations / both; affiliate mode at the end |
| Offer | Customer outcome, terms, approved proof and claims, forbidden claims |
| Audience | ICP, exclusions, countries, source restrictions and sample criteria |
| Data | Upload path, existing warehouse, API providers or BrowserBox; budget and key availability |
| Sender | Approved person/company, domain/inboxes, monitored reply path, signature/address/footer |
| Sequencer | Instantly / Smartlead; client PlusVibe only if chosen |
| CRM | Connect GHL? exact agency/location, field and stage mapping; avoid other-client tokens |
| SMS | Number/provider, registration, consent evidence/scope, opt-out behavior, recipient timezone/windows |
| Channels | Slack workspace, owner Member IDs, channel; optional Composio accounts |
| Model | Baseline Fireworks or reviewed alternative; spending limit |
| Conversion | Qualifying questions, booking link/calendar, escalation contact and response expectations |
| Release | Exact list/copy versions, caps, windows, stop thresholds, playbook and expiry |
| Affiliate | Approved partner terms/types, attribution source, payout escalation owner |

Store in the deployment’s private `onboarding.json`, never the repository. Record unknowns as holds. Keys are entered privately and only their presence/capability is reported. Report costs as current provider quotes, not stale source pricing.
